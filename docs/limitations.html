Separate the gates¶

Bounded D6 applies only to fields with frozen limits. REPORT_ONLY fields have no invented tolerance; missing fields make full coverage incomplete. E41 resources, F2 pre-mask events, restart and station skill are separate. Default WN3/PROD/Swiss F20 must pass E41. Opt-in composites require strict D6, complete inventory and NF0, with raw E41 FAIL disclosed as perf/robustness limits. F2 remains separate. Finite history does not justify intermediate negatives or repairs.

Original MYNN cold-start undefined initialization, P3/Jensen/WDM5 precision residuals and NTU source-diffusion negatives remain disclosed. Class-D producers are merged and the66 registered accepted scientific scopes are complete (65 full24h plus c45 accepted6h). Active green-roof/PV/aerosol branches remain refused; other unqualified regimes retain their recorded limits. GitHub release assets await owner authentication; remote runtime-table fetches fail until upload. Read the release notes and support matrix.

Input and nesting boundaries¶

Surface mosaic is refused. Crop/tile/map-selected irrigation needs valid geography; synthetic maps do not supply scientific truth. Options with only single-domain evidence are nested not validated where admitted. Actual refused combinations remain refused. Moving/vortex-following nests and unsupported chemistry/fire/hydrology/DA paths remain outside this release.

Performance and hardware¶

Historical speed/energy figures keep their measured version, hardware and clock definitions. Shared cold qualification time is not warm S1. Real multi-GPU scaling and new hardware extrapolations are not qualified measurements. The performance page retains dated evidence.

Historical science records¶

The v0.3.3 galleries retain raw rain/wind/cirrus failures and accepted source-specific annexes. They are not relabelled as new v0.4 observations. See the repository's full issue record.
